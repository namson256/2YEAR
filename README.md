# 🎓 2 Year | Core Software Engineering & Data Foundations

Welcome to the definitive repository for **Year 2**. This space serves as a central hub for all foundational programming concepts, network protocols, core database management, and data analytics implementations across Semester 1 and Semester 2, with an early emphasis on **Work-Based Learning (WBL)**.

---

## 📅 Semester 1

### 🌲 Data Structures And Algorithms
> **`COURSE OVERVIEW`**
> Focuses on the fundamental ways data is organized, stored, and manipulated in memory, alongside the logic required to process it efficiently. Topics include arrays, linked lists, stacks, queues, trees, graphs, and essential sorting and searching algorithms, with a strong emphasis on analyzing time and space complexity ($O(n)$ notation).

* **💡 Key Reflection:** This module completely changed how I approach coding. It taught me that writing code that just "works" isn't enough; it has to be computationally efficient. Figuring out recursion and mastering trees and graphs was tough, but learning how to choose the right data structure for a specific problem fundamentally upgraded my algorithmic thinking.

---

### 🗄️ Database `WBL`
> **`COURSE OVERVIEW`**
> A Work-Based Learning (WBL) module introducing relational database management systems (RDBMS). It covers the fundamentals of database design, entity-relationship diagrams (ERD), normalization (1NF to 3NF), and structured query language (SQL) commands for creating, reading, updating, and deleting data in an industry-like environment.

* **💡 Key Reflection:** Working with real-world database concepts via the WBL framework made me appreciate how data underpins every modern application. Normalization felt like a giant puzzle at first, but once it clicked, I realized how critical clean data schemas are to preventing data redundancy and ensuring structural integrity.

### 🏢 Software Engineering `WBL`
> **`COURSE OVERVIEW`**
> An industry-aligned module that covers the entire software development lifecycle (SDLC). Students explore agile and waterfall methodologies, requirements gathering, system specification, software architectural patterns, quality assurance testing, and professional documentation standards.

* **💡 Key Reflection:** This course took me out of the sandbox and showed me how software is actually built in teams. I learned that coding is only a fraction of the process—good communication, thorough documentation, and rigorous testing methodologies are what turn a messy project into reliable, production-grade software.

---

### 💻 System Development Technology
> **`COURSE OVERVIEW`**
> Explores the comprehensive tech stacks, environments, and developer tools required to build modern software systems. Topics include version control systems (Git), command-line interfaces, scripting languages, IDE optimization, environment configuration, and basic deployment environments.

* **💡 Key Reflection:** This module felt like receiving a developer's survival toolkit. Mastering Git workflow, branch management, and navigating the command line gave me the confidence to collaborate seamlessly on repositories. It felt less like a theoretical class and more like practical training for a day-to-day software engineering role.

---

### 🌐 Network Communications
> **`COURSE OVERVIEW`**
> Introduces the architectural frameworks and protocols that allow computers to communicate. Topics include the OSI and TCP/IP models, routing, switching, IP addressing (IPv4/IPv6), subnetting, and network security essentials that keep data moving securely across local and global networks.

* **💡 Key Reflection:** Demystifying what happens when a computer makes a web request was fascinating. Subnetting calculations were a bit of a headache initially, but understanding routing, switching, and transport layers gave me a concrete appreciation of how the infrastructure powering our applications actually functions globally.

## 📅 Semester 2

### 🚀 Technopreneurship Seminar
> **`COURSE OVERVIEW`**
> Explores the intersection of technology, innovation, and business creation. This seminar guides students through identifying market gaps, scaling innovative ideas, understanding intellectual property, business modeling, agile product pitching, and developing an entrepreneurial mindset in the tech space.

* **💡 Key Reflection:** As an engineering student, this course pushed me far out of my comfort zone by forcing me to think like a business founder. It’s easy to get obsessed with the tech stack, but this seminar proved that even the best code is useless if there isn't a viable market or user need for what you are building.

---

### 📦 Object Oriented Programming
> **`COURSE OVERVIEW`**
> Deep dives into the object-oriented paradigm (OOP) using languages like Java or C++. Key topics include the four main pillars of OOP—encapsulation, inheritance, polymorphism, and abstraction—along with design patterns, exception handling, and creating modular, highly reusable code structures.

* **💡 Key Reflection:** Learning OOP shifted my coding style from chaotic scripts to structured, modular architecture. Understanding polymorphism and inheritance completely changed how I design systems, making my code significantly easier to read, maintain, expand, and debug.

---

### ⛏️ Data Mining
> **`COURSE OVERVIEW`**
> Covers the techniques used to discover hidden, valid, and actionable patterns within massive datasets. Topics include data preprocessing, association rule mining, classification and clustering techniques, anomaly detection, and evaluation metrics used to discover meaningful insights from raw data.

* **💡 Key Reflection:** Data Mining felt like acting as a digital detective. It was incredibly satisfying to run clustering and association algorithms over messy data and see clear human behaviors and trends emerge. It laid a perfect analytical foundation for understanding how data drives strategic automation.

---

### 📊 Data Analytics Programming
> **`COURSE OVERVIEW`**
> Focuses on utilizing programming languages (typically Python or R) and specialized libraries (such as Pandas, NumPy, and Matplotlib/Seaborn) to clean, manipulate, explore, and visually map complex datasets to drive data-driven decision-making.

* **💡 Key Reflection:** This was an incredibly hands-on and practical module. Becoming proficient in data manipulation pipelines and exploratory data analysis (EDA) proved to me how much work goes into data preparation before any modeling can happen. Transforming rows of numbers into clean, telling charts was highly rewarding.

---

### ⚙️ Operating Systems
> **`COURSE OVERVIEW`**
> Examines the core software layer that manages hardware resources. Topics include process and thread management, CPU scheduling algorithms, memory management (virtual memory and paging), file systems, concurrency control, deadlocks, and system security structures.

* **💡 Key Reflection:** This module really pulled back the curtain on how a computer manages its physical resources. Working through CPU scheduling and learning how operating systems handle memory allocation made me a much more mindful programmer—allowing me to write code that respects memory and processing boundaries.
